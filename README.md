
# 🕊️ Tenda de Umbanda Sagrada Caboclo Samambaia e Cigano Pablo

Site institucional da **Tenda de Umbanda Sagrada Caboclo Samambaia e Cigano Pablo**, desenvolvido para apresentar a história, os princípios, a espiritualidade, a liderança e os canais oficiais de contato da casa.

O projeto foi desenvolvido com foco em uma experiência acolhedora, elegante, responsiva e alinhada à identidade visual da tradição da casa.

## 📌 Sobre o projeto

Este projeto consiste em um site institucional de página única (*one-page*), permitindo que os visitantes conheçam melhor a casa e encontrem informações importantes antes de realizar uma visita.

O site apresenta conteúdos sobre:

- A identidade e a proposta da Tenda;
- A história e a apresentação da casa;
- Os princípios de fé, caridade, respeito e acolhimento;
- A visão da casa sobre a Umbanda;
- A liderança espiritual;
- Registros fotográficos e momentos da casa;
- Orientações para visitantes;
- Canais de contato, redes sociais e localização.

## ✨ Funcionalidades

- Navegação por seções em uma única página;
- Menu responsivo para dispositivos móveis;
- Rolagem suave entre as seções;
- Efeito visual na barra de navegação durante a rolagem;
- Botão para voltar ao topo da página;
- Galeria de imagens;
- Filtros para organização da galeria;
- Animações de entrada dos elementos durante a rolagem;
- Layout adaptável para diferentes tamanhos de tela;
- Botões de contato via WhatsApp;
- Link para o perfil oficial no Instagram;
- Link para localização no Google Maps.

## 🎨 Identidade visual

A identidade visual foi desenvolvida com uma paleta inspirada em elementos naturais e terrosos, utilizando principalmente:

- Marrom escuro;
- Marrom terroso;
- Verde-mata;
- Verde-folha;
- Dourado;
- Tons de areia;
- Branco suave;
- Grafite.

A combinação busca transmitir acolhimento, espiritualidade, serenidade, conexão com a natureza e respeito à identidade da casa.

## 🚀 Como executar o projeto

Como o projeto é estático, não é necessário instalar Node.js, configurar banco de dados ou instalar dependências locais.

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Acesse a pasta do projeto

```bash
cd TUS
```

### 3. Abra o site

Basta abrir o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão **Live Server**, disponível no Visual Studio Code, para executar o projeto em um servidor local.

## ✏️ Como personalizar o projeto

### Alterar textos e informações

Os textos, títulos, informações institucionais e conteúdos da página estão no arquivo:

```text
index.html
```

### Alterar cores e estilos

As cores principais, fontes, espaçamentos, botões e demais estilos estão no arquivo:

```text
css/style.css
```

### Alterar interações

Os comportamentos de navegação, rolagem, galeria, botão de retorno ao topo e animações estão no arquivo:

```text
js/script.js
```

### Alterar imagens

As imagens utilizadas pelo site estão armazenadas na pasta:

```text
image/
```

Ao substituir uma imagem, mantenha o caminho e o nome do arquivo referenciado no HTML ou atualize o caminho correspondente.

## ⚠️ Observações importantes

- Verifique se todos os caminhos de imagens utilizados no `index.html` correspondem aos arquivos existentes no projeto.
- Confira se o caminho do favicon e da logo está correto antes de publicar o site.
- O projeto depende de CDNs para carregar o Bootstrap, os ícones e as fontes externas.
- O site não utiliza banco de dados nem backend.
- Os links de WhatsApp, Instagram e localização devem ser conferidos antes da publicação definitiva.
